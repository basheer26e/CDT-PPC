# تقرير اختبار CDT-PPC

طريقة الاختبار: استخراج دوال الحساب الفعلية من `index.html` وتشغيلها بالأرقام، تشغيل التطبيق الكامل داخل jsdom، وتشغيل ملفات SQL على Postgres حقيقي (PGlite) مع محاكاة `auth.uid()` ودور `authenticated`. اختبارات عشوائية: ≈10,000 سيناريو (MPS/MRP/تسوية/صيانة متعددة/أعطال الآلة/تأخير الموردين/ما-لو/تكاليف). الحالة النهائية: **56 اختباراً نجحت، 0 فشل، 0 معلّقة**. وللتأكد أن الاختبارات تكشف الأخطاء فعلاً أُعيد إدخال كل عيب على حدة (21 تحويراً) فتفشل الاختبارات المقابلة في كل حالة.

### الدفعة الخامسة: الصفحة سوداء بدون VPN (تصميم التحميل نفسه)

**اللقطة:** شاشة سوداء تماماً وشريط التحميل في بدايته، بلا شاشة التحميل ولا أي رسالة.
**السبب:** رأس الصفحة كان يحمّل **ستة سكربتات متزامنة** من موقعين خارجيين (React، ReactDOM، Babel بحجم 2.8 ميغابايت، xlsx، PapaParse، Tailwind) والمتصفح لا يرسم أي شيء، حتى شاشة التحميل، حتى تنزل كلها. فإن بطؤ أو حُجب أحدها بشبكة الزائر (بدون VPN في حالتك) بقيت الصفحة سوداء. وهذا سيصيب أي زائر لمنشور LinkedIn بشبكة مماثلة. (يُرجَّح هذا السبب لأن لقطات العمل السابقة كان فيها VPN وهذه لا؛ لم أتمكن من فحص شبكتك مباشرة.)

| # | التغيير | الأثر |
|---|---|---|
| 26 | كل المكتبات داخل المستودع (`vendor/`) بدل CDN | لا يلزم إلا موقعك نفسه (github.io) |
| 27 | الكود يُترجم عند البناء (`assets/app.js`) بدل Babel بالمتصفح | حُذف Babel (2.8 ميغابايت) |
| 28 | Tailwind مبني مسبقاً (`assets/tailwind.css` ≈ 25 كيلوبايت) بدل JIT من CDN | بنفس إصدار 3.4.17؛ التقاط الأصناف بزحف فعلي على كل حالات الواجهة (291 صنفاً، 0 مفقود) |
| 29 | شاشة التحميل أول ما يُرسم (لا سكربت بالرأس) ومكتبتا Excel/CSV بـ`defer` | الصفحة تظهر فوراً |
| 30 | سكربت الأخطاء المبكر أُعيدت كتابته: يعرض اسم الملف الذي فشل تحميله، ويُبقي السبب الجذري ظاهراً | لا شاشة صامتة |
| 31 | رابط الملفات بوسم نسخة (`?v=hash`) | تنتهي مشكلة النسخة القديمة المخزّنة بالمتصفح |

**الحجم:** من نحو 4.7 ميغابايت من موقعين خارجيين (متزامنة) إلى ≈ 0.6 ميغابايت من موقعك (HTML 8 كيلوبايت + CSS 25 + React 142 + التطبيق 400؛ تضغطها GitHub Pages)، ومكتبة Excel (0.9 ميغابايت) تُحمَّل لاحقاً بلا حجب.

**اختبارات جديدة:** الملفات المبنية محدّثة (تفشل لو نسيت `npm run build`)، لا مورد خارجي ولا سكربت بالرأس، شاشة التحميل قبل أي سكربت، `app.js` صالح، تغطية كل صنف CSS مستخدم، وإقلاع الصفحة المبنية بالعربية والإنجليزية، وفشل تحميل `app.js` أو React يُظهر رسالة واضحة. وعند حقن عطل بكل منها (تعديل المصدر بلا بناء، صنف بلا CSS) تفشل.

## ما سُدّ من النواقص
- `supabase/functions/ai-proxy` كان مستدعى من التطبيق (`functions.invoke("ai-proxy")`) وغير موجود بأي ملف. كُتب، **لكنه لم يُختبر على مشروع Supabase حقيقي**.
- لا README ولا `.gitignore` ولا اختبارات ولا CI.

## سلوكيات مقصودة (ليست أخطاء، موثّقة بـREADME)
1. التقييد بالمادة يستهلك مخزون الأمان حتى الصفر ويُعلَّم الأسبوع «نقص» (سياسة نمذجة؛ غيّرها لو سياسة مصنعك أن مخزون الأمان لا يُمَس).
2. التسوية بين الأسابيع تُلغى تلقائياً لو حرّكت موعد صيانة، وتتجاهل أسابيع أعطال الآلة.
3. عند ترقية قاعدة قديمة لا يُضاف `NULLS NOT DISTINCT` تلقائياً (قد يفشل على بيانات مكرَّرة قديمة) — خطواته اختيارية بنهاية `03_security_hardening.sql`.

## ما لم يُختبر
- الاتصال بمشروع Supabase حقيقي ولا بـGemini/OpenRouter/Claude حقيقية (استُخدمت عملاء تجريبية).
- تحميل المكتبات من CDN فعلياً (بما فيه رابط Tailwind المثبَّت) والمتصفحات الفعلية (اختُبر في jsdom)، وتصدير/استيراد Excel.
- AnyLogic وStreamlit غير موجودين ضمن الملفات المرفوعة.
- أداء التحميل على جوال حقيقي بشبكة بطيئة (قِسته نظرياً بالحجم فقط).
