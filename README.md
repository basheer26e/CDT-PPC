# CDT-PPC — التوأم الرقمي المعرفي لتخطيط ومراقبة الإنتاج

> **EN:** Cognitive Digital Twin for Production Planning & Control — a static web app (React, prebuilt — no CDN, no in-browser compilation) with MPS/MRP, capacity & maintenance modelling, what-if scenarios, AI planning agents, and an optional multi-tenant Supabase backend. Graduation project, Industrial & Manufacturing Systems Engineering.

مشروع تخرج: نظام تخطيط إنتاج لمصنع (حالة دراسية: مصنع سمن) يحوّل الطلب الأسبوعي إلى خطة إنتاج رئيسية (MPS) ثم احتياج مواد (MRP)، مع الطاقة الإنتاجية والصيانة والتكاليف وسيناريوهات «ماذا لو؟» ووكلاء ذكاء اصطناعي يفسّرون الخطة.

## المحتويات

```

```

## إن لم يفتح الموقع عندك بدون VPN

الصفحة نفسها لا تحمّل أي شيء من خارج موقعها، فلو بقيت لا تفتح إلا بـVPN فالمحجوب غالباً هو `github.io` نفسه في شبكتك (حجب DNS أو IP من مزوّد الخدمة)، وليس عطلاً بالتطبيق. جرّب بالترتيب:
1. افتح موقعاً آخر على `github.io` بلا VPN، مثل `https://google.github.io/styleguide/`. إن لم يفتح فالحجب من الشبكة.
2. غيّر DNS: أندرويد ← الإعدادات ← الشبكة ← DNS الخاص ← اسم المضيف: `dns.google` (أو `one.one.one.one`).
3. جرّب شبكة أخرى (بيانات الجوال بدل الواي فاي أو العكس).
4. للعرض بلا شبكة أصلاً: حمّل `downloads/CDT-PPC-offline.html` وافتحه مباشرة من الجهاز.

## التعديل والبناء

عدّل `src/app.jsx` (أو القالب) ثم شغّل:
```bash
npm install      # مرة واحدة
npm run build    # يُحدّث index.html و assets/ و vendor/
npm test         # يتأكد أن الملفات المبنية محدّثة وكل شيء يعمل
```
ارفع للمستودع **كل** الملفات الناتجة (`index.html` و`assets/` و`vendor/` مع `src/`). اختبار «الحداثة» يفشل لو نسيت `npm run build`.

**لماذا مبني مسبقاً؟** النسخة القديمة كانت تحمّل ستة سكربتات متزامنة من موقعين خارجيين (أكبرها Babel بحجم 2.8 ميغابايت) قبل أن يرسم المتصفح أي شيء؛ فإن بطؤ أو حُجب أحد المواقع بشبكة الزائر بقيت الصفحة سوداء. الآن كل شيء من موقعك نفسه، وشاشة التحميل تظهر فوراً، والترجمة تتم مرة واحدة عند البناء.

## التشغيل

**محلياً:** افتح `index.html` في المتصفح (لا يحتاج إنترنت للتشغيل، فكل المكتبات داخل المستودع) ثم اضغط «المتابعة محلياً بدون تسجيل دخول». البيانات تُحفظ في متصفحك (`localStorage`).

**على GitHub Pages:** Settings ← Pages ← Source: *Deploy from a branch* ← `main` / `/ (root)`. يظهر التطبيق على `https://<اسمك>.github.io/<المستودع>/`.

## مفاتيح الذكاء الاصطناعي (الوضع المحلي)

تُدخَل من داخل التطبيق وتُحفظ في `localStorage` بمتصفحك فقط — **لا تضعها في الكود أبداً**. تنبيه: على GitHub Pages كل مستودعاتك تشترك بنفس الـorigin (`<اسمك>.github.io`) فتشترك بنفس `localStorage`؛ استخدم مفتاحاً بحصة محدودة، أو استخدم الوضع السحابي مع `ai-proxy`. اسم نموذج Claude داخل الكود (`claude-sonnet-5-5`) تحقق منه من وثائق Anthropic لأن الأسماء تتغير.

## الوضع السحابي (اختياري: تسجيل دخول + مصانع متعددة معزولة)

1. أنشئ مشروعاً في [supabase.com](https://supabase.com).
2. من **SQL Editor** شغّل `sql/01_schema.sql` كاملاً (مرة واحدة على مشروع فاضٍ).
3. أضف مصنعاً ومستخدماً بالقالب في القسم 4 من نفس الملف (أنشئ المستخدم من Authentication ← Users أولاً).
4. في `src/app.jsx` ابحث عن `SUPABASE_URL` وضع رابط المشروع و**anon public key** (المفتاح العام مصمَّم ليظهر في المتصفح — الحماية الفعلية هي سياسات RLS. **لا تضع مفتاح `service_role` أبداً**).
5. (للذكاء الاصطناعي المركزي) انشر `supabase/functions/ai-proxy` بالخطوات في رأس ملفه.
6. **تحقق بنفسك قبل أي استخدام حقيقي:** أنشئ مصنعين تجريبيين، وتأكد أن مستخدم المصنع ب لا يرى أي بيانات للمصنع أ.

**ما الذي يُزامَن سحابياً:** المواد (BOM والمخزون) وسرعة الخط وساعات الوردية. **يبقى محلياً فقط:** تكلفة الوحدة، أيام العمل/الورديات/نسب العيوب، FGI، الصيانة، التكاليف، خطة المبيعات. (تغيير هذا يتطلب أعمدة جديدة بالمخطط.)

## الاختبارات

```bash
npm install
npm test
```

تشغّل 59 اختباراً على الكود الفعلي داخل `index.html`: منطق MPS/MRP/الصيانة/ما-لو (مع اختبار عشوائي لـ3000 سيناريو يشمل أعطال الآلة وتأخير الموردين وصيانات متعددة)، الواجهة كاملة في jsdom (كل التبويبات، ما-لو، تقرير PDF، الدخول السحابي بعميل تجريبي)، واللغة (الواجهة الإنجليزية بلا أي حرف عربي في 26 صفحة والمعالج وتقرير PDF، وتبديل اللغة أثناء التشغيل)، وملفات SQL على Postgres حقيقي (PGlite) للعزل والأدوار، وتثبيت مكتبة Supabase، وسلامة البناء (محدَّث، بلا مورد خارجي، شاشة التحميل أولاً، تغطية كل أصناف CSS المستخدمة)، وإقلاع الصفحة المبنية كما يفعل المتصفح مع محاكاة فشل تحميل الملفات. تُشغَّل تلقائياً عند كل push عبر GitHub Actions.

## اللغة

الواجهة عربية وإنجليزية بالكامل (زر `AR / EN` في أعلى الصفحة)، وتشمل القوائم والجداول والتنبيهات المحسوبة (الجدوى والصيانة) ورسائل الأخطاء وتقرير PDF (ويصير LTR بالإنجليزية). التبديل فوري حتى للنصوص التي يحسبها المحرك.

- **وكلاء الذكاء الاصطناعي:** تعليماتهم عربية، وبالواجهة الإنجليزية يُضاف طلب صريح بالإجابة بالإنجليزية.
- **لا يُترجَم:** ما يكتبه المستخدم (أسماء المنتجات والمواد) وما حُفظ سابقاً بلغة وقت إنشائه، مثل اسم الخطة الافتراضي.
- لإضافة نص جديد بالكود استخدم `__t("عربي", "English")` أو `__tf("أسبوع {0}", "week {0}", [قيمة])`؛ واختبار اللغة يفشل لو بقي نص عربي بلا ترجمة في الواجهة الإنجليزية.

## شاشة الدخول

بدون إعداد Supabase (الوضع الافتراضي للنشر) يدخل الزائر **التطبيق مباشرة** ويعمل محلياً (بياناته تبقى بمتصفحه). تظهر شاشة تسجيل الدخول فقط عندما تضع `SUPABASE_URL` و`SUPABASE_ANON_KEY` وتُفعّل الوضع السحابي، وفيها زر «المتابعة محلياً» لمن لا يملك حساباً.

## الأدوار في الوضع السحابي

تُفرَض بقاعدة البيانات (RLS) وليس بالواجهة فقط:

| الدور | القراءة | إضافة/تعديل BOM والمخزون وخط الإنتاج | إنشاء/تعديل/حذف المنتجات | الحذف |
|---|---|---|---|---|
| `admin` | ✓ | ✓ | ✓ | ✓ |
| `member` | ✓ | ✓ | ✗ | ✗ |

لا أحد من المستخدمين يستطيع تعديل `profiles` أو `organizations` (إنشاء المصانع وتعيين الأدوار من SQL Editor فقط). ولا يمكن ربط صف بمنتج أو مادة من مصنع آخر.

## سياسات النمذجة (قرارات مقصودة)

- **مخزون الأمان:** عند تقييد الإنتاج بنقص مادة خام (فات أوان طلبها)، تُستهلك المادة المتوفرة حتى الصفر بدل التوقف مبكراً للحفاظ على مخزون الأمان؛ فتظهر تلك الأسابيع بتحذير «نقص» وتنخفض درجة الجدوى. غيّر هذا السلوك في `computeMaterialCaps` لو سياسة مصنعك أن مخزون الأمان لا يُمَس.
- **أسابيع «فات الأوان»:** لا طلب صالح لها (`order = 0`)؛ يظهر «عجز» بدل كمية، ويُغطّى بأول طلب يصل بعد مدة التوريد.
- **التسوية بين الأسابيع** تُلغى تلقائياً لو حرّكت موعد صيانة دورية، وتُتجاهل أسابيع أعطال الآلة.
- نسبة الاستخدام تُقتطع عند 999.9% (تفادياً لأرقام لا نهائية عند معدل إنتاج صفر).

## ما لم يُختبر

- الاتصال بمشروع Supabase أو Gemini/OpenRouter/Claude حقيقي (استُخدمت عملاء تجريبية)، وتحميل المكتبات من CDN، والمتصفحات الفعلية، وتصدير/استيراد Excel.
- `ai-proxy` لم يُنشر على مشروع حقيقي.
